## 使い方

```python
from chi_sr import ChiSR
model = ChiSR("chi_sr_tables.npz")
chi_T, regime = model(M_msun, chi0, T_yr, mu_eV, f_GeV)   # どれも配列でよい(ブロードキャスト)
```

| 入力 | 単位 | 意味 |
|---|---|---|
| `M_msun` | $M_\odot$ | BH の質量(**生まれたときの質量**。下の「入力の質量」) |
| `chi0` | — | 生まれたときのスピン($0\le\chi_0<1$) |
| `T_yr` | 年 | 年齢(生まれてから合体まで) |
| `mu_eV` | eV | ALP の質量 $\mu$ |
| `f_GeV` | GeV | ALP の崩壊定数 $f$(自己相互作用 $\lambda=\mu^2/f^2$、引力) |

範囲の外の入力(有限でない値、$\chi_0\notin[0,1)$、$M,\mu\le0$、$f<10^{-40}$ GeV、$T<0$)は `ValueError` で止まる。$M$ や $\mu$ が $10^{\pm300}$ のような値のときと、$\alpha\gg1$ で $f$ が極端に小さいときは、numpy の警告(あふれなど)が出ることがある。そのときも値は $\chi_0$、印は 0 か 3 で、例外にはならない(E20)。

出力の `chi_T` は年齢 $T$ のあとのスピン、`regime` はどの領域で計算したかの印である。

| `regime` | 意味 |
|---|---|
| 0 | 超放射しない($\chi_0$ が 211 と 322 の臨界以下で、433 も年齢のうちに飽和しない)。$\chi_T=\chi_0$ |
| 1 | 自己相互作用の固定点(三準位)。211 から育つ BH も 322 から育つ BH も、322 の臨界まで下がりうる。三準位の外の準位(411・433)は年齢のうちに育たない(422 は調べていない。限界 2) |
| 2 | 自由場(211 が飽和して臨界へ、そのあと 322 の段階)。または 322 から育つ BH で、自己相互作用が飽和までに効かず 322 が飽和する場合 |
| 3 | この模型の外。$\chi_T=\chi_0$ を返す(予言ではない): 固定点で $\alpha>0.30$、値の表の下($\alpha<0.008$。固定点では $\alpha<0.01$ で $f<10^8$ GeV の点も)で雲が年齢のうちに育ちうる点、$\alpha>0.5$、211・322 は超放射しないが 433($m=3$)が年齢のうちに飽和しうる点、表の範囲の中なのに値を引けない点($M$ が 1–300 $M_\odot$ の外、$\mu T>0.13$ eV yr、重みのある節がその年齢まで解けていない)、$\chi_0>0.995$ で超放射する点 |
| 4 | 値は返すが、模型の外の準位が年齢のうちに育ちうるので近似は粗い: 固定点で 411、433、211 の臨界より上の 544(限界 2)、自由場で止まったスピンから 433 が飽和しうる、または自由場で 544 の超放射まで進んで 433 の臨界より下にいる。**約束の外** |
| 5 | 値は表の補間だが、表の節のあいだで補間できない所(限界 3): 速い段差の時刻が節のあいだで急に変わる所、段差の時刻が $\alpha$ の節のあいだで折れていて値がそれに敏感な所、段のあとの平らな所で角の節の値が割れている所。**約束の外** |

印 0・1・2 だけが下の約束を満たす。印 1・2 の区別は半解析の領域の判定から付け、値はどちらも表から引く。

### 入力の質量

`M_msun` は**生まれたときの質量**である。BH は超放射で質量を失う(自由場の側で最大 11%)ので、観測された質量は少し小さい。観測された質量をそのまま渡したときのずれは次のとおり(基準の運動論で初期の質量から最後の質量とスピンを出し、最後の質量で関数を呼んで比べた。$M$ 8–60 $M_\odot$、$\mu$ 0.3–1.2 $\times10^{-12}$ eV、$\alpha\le0.3$、年齢 $10^7$–$6\times10^9$ 年)。

| $f$ [GeV] | 質量の減少(中央値、最大) | スピンのずれ(95% 点、最大) | 0.03 を越える割合 |
|---|---|---|---|
| $10^{11}$–$10^{13}$ | 0.00%、2.0% | 0.0039、0.008 | 0.0% |
| $10^{14}$–$10^{16}$ | 0.48%、2.6% | 0.0064、0.012 | 0.0% |
| $10^{17}$–$10^{20}$ | 1.69%、11.1% | 0.0212、0.038 | 1.3% |

窓($f\sim10^{12}$ GeV)では無視できる。$f\gtrsim10^{17}$ GeV(自由場に近い側)を扱うときは、質量の減少を解析の側で考える。

### 印 3・4・5 の標本の扱い

印 3・4・5 の値は予言ではない(印 3 は $\chi_0$ をそのまま返す)。集団解析では次のように扱うのがよい。

- **落とさない**。印のついた標本を除いて規格化し直すと、重い BH・速く回る BH ほど除かれるので、$(\mu,f)$ に依存した偏りが出る。
- **割合を記録する**。$(\mu,f)$ の格子点ごとに印 3・4・5 の割合を出し、効いている質量の範囲で割合が大きい点は「この模型では決まらない」とする。
- **両端で挟む**。印のついた標本を (i) スピンは変わらない($\chi_T=\chi_0$)、(ii) 322 の臨界まで落ちる($\chi_T=\min(\chi_0,\chi_c^{(322)})$。`model.chic(model.alpha(M, mu), 2)` で引ける。$m=3$ まで考えるなら `model.chic(..., 3)`)の二通りに置いて尤度を計算し、結論が変わらない $(\mu,f)$ だけを使う。

|---|---|---|---|---|---|---|

$\mu$ が大きいと、重い BH から順に印 3($\alpha>0.5$ か、固定点で $\alpha>0.30$)になる。$\mu=1.5\times10^{-12}$ eV では 40 $M_\odot$ より重い 1 世代目の 86% 以上が印 3 で、速く回る BH は 10 $M_\odot$ より上の半分以上が約束の外にある。$(\mu,f)$ の地図がこの模型で決まるのは、およそ $\mu\lesssim10^{-12}$ eV である。速く回る重い BH(40 $M_\odot$ 以上、$\chi_0\gtrsim0.6$)は、$\mu=0.71\times10^{-12}$ eV でも大半が約束の外にある。

### 並列で使う

`ChiSR` は pickle できる。pickle の中身は表の場所(絶対パス)だけで、受け取ったプロセスが同じ表を一度だけ読む。`multiprocessing.Pool` や、それを使うサンプラーにそのまま渡せる。別の計算機に渡すときは、同じ場所に表が要る。メモリは 1 プロセスあたり約 0.4 GB(表。読むときに一時的に 1.0 GB)に、呼び出しの作業領域が加わる($10^6$ 個を一度に渡すと、合わせて最大約 1.4 GB。足りなければ $2\times10^5$ 個ほどに分けて呼ぶ。値は分け方によらない)。

速さ: $10^6$ 個の標本で 6 秒(1 世代目らしい入力)から 14 秒($\chi_0$ が一様)、Apple M3、numpy 2.3(E18 の版は同じ計算機で 5–11 秒。折れの判定のぶん遅い)。表を読むのに約 2.5 秒かかる。

## 約束と照合(研究ノート E18・E19)

下の「E19 の版」の数は、いまの版(E20。$f$ の下限を加えただけ)にもそのまま当てはまる。値を計算する所は同じで、E19 の照合の入力に対する出力は、x86-64 でも保存した出力と一致する(E20)。

**約束**: 印 0・1・2 の値は、基準の運動論と
$$|\chi_\mathrm{SR}(T)-\chi_\mathrm{ref}(T')|\le0.03\quad\text{を満たす } T' \text{ が } |\ln(T'/T)|\le0.02 \text{ の中にある。}$$
速い段差(雲が飽和してスピンが急に落ちる所)の時刻は 2% までずれてよい、という意味である。0.03 は GW のスピンの測定誤差(0.1 程度)より十分小さい。これは標本で確かめた統計的な主張で、保証ではない(下の「E19 の照合」に、点の数と、越えたセルの数を書く)。

**基準の運動論**(プロジェクトの `research/calc/fp3.py` の `evolve3m`): 211・322・544 の占有数と、BH の質量・角運動量を 1 個の量子から時間で解く。超放射の率は相対論的な表、自己相互作用は BGLS の Table V・VI、BH へのエネルギーの戻り、雲からの重力波の過程(BGLS Table IV)を入れる。$\infty$ への過程を切ると、角運動量は $2\times10^{-6}$、エネルギーは $7\times10^{-6}$ の精度で保たれる。

**表**: 基準の運動論を $\alpha$ 0.008–0.5 の 47 点、初期スピンの臨界に対する位置 25 点(211 から育つ側と 322 から育つ側)、$f$ $10^8$–$10^{20.5}$ GeV の 51 点、$M$ 1・300 $M_\odot$ で解いた(239,700 節)。各節で、スピンの進み具合(段の幅の 1% 刻み)を越えた時刻を持ち、節のあいだはその時刻を補間する。$M$ は $\ln(N_0M^2)$ を通してだけ効き、時刻は $M$ について線形に混ぜる。$f>10^{20.5}$ GeV は上端の値(自己相互作用は効かない)、$f<10^8$ GeV は半解析の値(ほぼ何も起きない領域で、照合で確かめた)。$\alpha<0.008$ は、雲が育つ前の点だけ $\chi_0$ を返す(育ちうる点は印 3)。

**E19 の照合**(`research/calc/e19_validate.py`): 表にも規則にも使っていない点で、年齢を細かくとって比べた。速い段差の時刻のずれは、年齢の幅 3–10% にしか現れないので、E18 の 40 点の年齢では見逃していた。

- 点: コードを確定したあとで作った新しい 4,800 点(seed 1903)。E18 と同じ 4 つの層(各 750 点)に、$\alpha$ が率の切り替え(0.03、0.1)を挟む表のセルとその両側の層、$\alpha$ 0.004–0.012 の層(各 600 点。$M$ 2–200 $M_\odot$、$f$ は半分を $10^{16}$–$10^{20.5}$ GeV に寄せる)を加えた。
- 年齢: 基準の曲線を持つ格子の 2382 点($10^5$–$1.4\times10^{10}$ 年。年齢の窓は $|\ln(T'/T)|\le0.0199$)。

## 模型

値は上の表から引く。以下の半解析は、表の範囲の外($f<10^8$ GeV)の値と、印 1・2・4 の判定に使う。

- **重力の微細構造定数**: $\alpha=GM\mu/\hbar c=0.0748\,(M/10M_\odot)(\mu/10^{-12}\,\mathrm{eV})$。
- **超放射の率**: 211・322 は Kerr 時空の Klein–Gordon 方程式を連分数法(Dolan, arXiv:0705.2880)で解いた表(211 で $\alpha\ge0.03$、322 で $0.1\le\alpha\le0.52$)。範囲の外と 433・544 は解析式(Baumann+ arXiv:1908.10370 の式 2.32–2.34)。占有数の率で、振幅の率の 2 倍。表と解析式の切り替え($\alpha=0.03$、0.1)で率は不連続で(限界 7)、ここが段差の時刻の折れになる(限界 3)。
- **自己相互作用の過程**(Baryakhtar+ arXiv:2011.11646、以下 BGLS、Table V・VI。占有数を $\varepsilon=N/(GM^2/\hbar c)$ で数え、率は $\mu(M_\mathrm{Pl}/f)^4$ を掛ける。BH が吸収する過程には $\tilde r_+$ も掛ける。$M_\mathrm{Pl}=1.22\times10^{19}$ GeV):

  | 過程 | 率 |
  |---|---|
  | $211\times211\to322\times\mathrm{BH}$ | $4.3\times10^{-7}\alpha^{11}$ |
  | $322\times322\to211\times\infty$ | $1.1\times10^{-8}\alpha^{8}$ |
  | $322\times322\to544\times\mathrm{BH}$ | $1.9\times10^{-9}\alpha^{11}$ |
  | $544\times544\to322\times\infty$ | $4.4\times10^{-11}\alpha^{8}$ |
  | $322\times544\to211\times\infty$ | $6.1\times10^{-11}\alpha^{8}$ |
  | $544\times544\to211\times\infty$ | $4.2\times10^{-13}\alpha^{8}$ |

- **固定点**: 三準位の式の安定な固定点で回転を失う。
  - 211 の臨界より上: (211, 322)。$\varepsilon_{211}=(2/\sqrt3)\sqrt{\gamma_{211}\gamma_\infty}/\gamma_\mathrm{BH}$(BGLS の式 55 に $\gamma_{322}$ の補正)。
  - 211 の臨界より下: 211 が空の (322, 544)。$\varepsilon_{322}=(2/\sqrt3)\sqrt{\gamma_{322}\gamma_d}/\gamma_c$、$\dot\chi=-2\gamma_{322}\varepsilon_{322}$。211–322 の組と同じ形。
  - 自己相互作用の率はどれも $(M_\mathrm{Pl}/f)^4$ に比例するので、どちらでも $\dot\chi=\mu(f/M_\mathrm{Pl})^2H(\alpha,\chi)$。そこで $I(\alpha,\chi)=\int_\chi^{0.995}d\chi'/|H|$ を表にし、$I(\alpha,\chi_T)=I(\alpha,\chi_0)+\tau$($\tau=\mu(f/M_\mathrm{Pl})^2T$)を解く。
  - スピンは $(\alpha,\chi_0,\tau)$ の 3 つの量だけで決まる。したがって $f$ と年齢 $T$ は $f^2T$ の形でしか入らない。
- **211 から育つ BH の判定**(BGLS の式 53・56): 固定点の占有数 $\varepsilon_\mathrm{eq}$ と行き過ぎ $\varepsilon_\mathrm{th}=\sqrt{2\gamma_{211}\ln(GM^2)/\gamma_\mathrm{BH}}$ が、どちらも飽和の量 $\chi_0-\chi_c^{(211)}$ より小さければ固定点、そうでなければ自由場。固定点では、1 個の量子から育つ時間を年齢から引き、行き過ぎで失う $\varepsilon_\mathrm{th}$ を初期スピンから引く。
- **322 から育つ BH**($\chi_c^{(322)}<\chi_0\le\chi_c^{(211)}$)の判定: 同じ形で、$\varepsilon'_\mathrm{eq}=(2/\sqrt3)\sqrt{\gamma_{322}\gamma_d}/\gamma_c$ と $\varepsilon'_\mathrm{th}=\sqrt{2\gamma_{322}\ln(GM^2)/\gamma_c}$ を $(\chi_0-\chi_c^{(322)})/2$ と比べる。固定点では、322 が育つ時間を年齢から引き、$2\varepsilon'_\mathrm{th}$ を初期スピンから引く。そうでなければ 322 が飽和して、BH の質量の減少を入れた 322 の臨界へ。$\mu=0.71\times10^{-12}$ eV の例では、自由場になるのは $f\approx1.7\times10^{17}$ GeV から。
- **臨界スピン**: 相対論的な率(211・322 の表、外は解析式)が 0 になるスピンを $\alpha=0.003$–0.6 で表にし、固定点の表、領域の判定、自由場の飽和のすべてで使う。率の表の端($\chi=0.995$)より上に臨界がある点($\alpha\approx0.45$ 以上)で、率を引けない BH は印 3。
- **表の引き方**: 両隣の $\alpha$ の節で $I$ に $\tau$ を足してそれぞれ厳密に逆に引き、$\alpha$ について線形に混ぜる($\tau\to0$ で $\chi_T=\chi_0$)。
- **自由場の側**: 211 は 1 個の量子から $\ln N_\mathrm{sat}\approx180$ 回の $e$-fold で飽和し、臨界スピン($m\Omega_H=E_n$)まで落ちる。BH の質量の減少を入れる。そのあと:
  - $f\le10^{17}$ GeV: 固定点の表で 322 の臨界へ下がる。
  - $f>10^{17}$ GeV: 322 を $t=0$ から 1 個の量子として $e$-fold を積む(粗い近似。表の範囲の中では使わない)。

## 限界(使う前に読む)

1. **印 3**(値は $\chi_0$ のまま。予言ではない): 固定点で $\alpha>0.30$ の点(表は $\alpha\le0.5$ まであるが、印 4 の判定の表がこの範囲なので、まだ使っていない)、$\alpha>0.5$ の点、値の表の下($\alpha<0.008$)で雲が年齢のうちに育ちうる点、433($m=3$)が年齢のうちに飽和しうる点(433 の自己相互作用は入れず、自由場の飽和の時間で判定)、表の範囲の中なのに値を引けない点、$\chi_0>0.995$ で超放射する点。重い BH と大きい $\mu$ で割合が大きい(「印 3・4・5 の標本の扱い」の表)。
2. **印 4 と、判定に入っていない 422**: 固定点で、411・433・544 の増加率が BH の降下のあいだに $\ln(GM^2)\approx180$ を超える $e$-fold を稼ぐ点(322 の臨界まで下がった BH は、433 の超放射も見る)。
   - 増加率は、BH が吸収する過程すべてに有限 $\alpha$ の補正(Witte & Mummery の図から読んだ $C_\mathrm{BH}$)を掛けて評価する。このとき 433・544 は $\alpha\gtrsim0.15$、411 は $\alpha\gtrsim0.18$ で、211 の臨界より上で育つ(BGLS の記述と合う)。補正なしでは 433 だけが $\alpha\gtrsim0.27$ で育つ。411 の超放射の率は Leaver の連分数法の表。
   - 211 の臨界より下の (322, 544) の固定点では、$\alpha\le0.30$ で 411・433 は育たない。322 から育つ BH と 211 の臨界より下への降下は、ほぼ印 1 になる。
   - 自由場の側では、止まったスピン(322 の臨界など)から 433 が年齢のうちに飽和しうる点が印 4(E17)。三準位の模型の中で 544 の超放射まで進み、返すスピンが 433 の臨界より下になった点も印 4(E19。433 の率は 544 の率より大きく、先に飽和するはずなので)。
   - **422 は判定に入っていない**(E19)。(211, 322) の固定点では、$211\times211\to422\times\mathrm{BH}$($1.5\times10^{-7}\alpha^{11}$)で育ち、$322\times422\to211\times\infty$($1.6\times10^{-8}\alpha^{8}$)で失う。主要項では失うほうが 2.1 倍大きく、422 は育たない。ただし BH が吸収する二つの過程($\to422$ と $\to322$)の相対論的な補正の比が 2.1 倍を越えれば育つ(Witte & Mummery は、422 が中間の $\alpha$ で $211\times211$ の散乱から育ちうると述べている)。(322, 544) の固定点では、422 の超放射の率は 322 の 0.60–0.62 倍で正であり、育つかどうかは 544 を含む過程の率で決まる。これは確かめていない。
   - 印 4 の値の誤差: 三準位の基準の運動論とは最大 0.17(0.4% が 0.03 を越える)。五準位(211・322・411・433・544)の ODE と比べた例($\alpha=0.22$、$\chi_0=0.9$)では最大 0.072。411 のあとに育つ 422 と、433 による $m=3$ の回転の減少は入れていない。
3. **印 5**: 値は表の補間のまま返すが、節のあいだで補間できない所。三つの場合がある。
   - **速い段差の時刻が節のあいだで急に変わる所**(E18): 雲の段の切り替わり(たとえば 322 の育ち方の機構が変わる所)で、段差の時刻が $f$ や $\alpha$ について 0.1 dex のうちに 1 dex 近く飛ぶ。角の節の値の幅が 0.06 を越え、しかも段差の時刻の曲がりが 0.05 dex を越えるセル。
   - **段差の時刻が $\alpha$ の節のあいだで折れている所**(E19): 隣り合う $\alpha$ の節の、同じ進み具合に届く時刻を、下の 2 節と上の 2 節からそれぞれ直線で延ばして比べ、どちらの延長も 2%(約束が許す時刻のずれ)より大きく外れる所を折れとする。折れの分だけ時刻を前後にずらしたときに値が 0.015 より変わる点が印 5。原因は基準の運動論の側にある: 超放射の率が表と解析式で切り替わる $\alpha=0.03$(211)と 0.1(322)での不連続と、322 の率の表の $\alpha=0.10$–0.125 の節の誤差(限界 7)。$\mu=0.71\times10^{-12}$ eV では、切り替えを挟む表のセルは 18.7–20.4 $M_\odot$ と 5.3–5.8 $M_\odot$ にあたる。窓($f\sim10^{12}$ GeV)の 211 から育つ BH は、降下が 211 の率で決まるので、ほとんど影響を受けない。
   - **段のあとの平らな所で、角の節の値が割れている所**(E19): 表は、進み具合の準位ごとの時刻を節のあいだで混ぜる。重みのある角の節のうち一つでも次の準位に届かないと、補間はそこで止まり、値は進みのいちばん遅い節の値になる(その節の重みが小さくても)。BH の質量が減ったあとの臨界の値などが節によって違うと、その差だけずれうる。止まった所で角の節の値の幅が 0.02 を越える点が印 5。
   - 集団解析での扱いは「印 3・4・5 の標本の扱い」。
4. **自己相互作用の率は主要項**: Kerr 時空での補正は、$211\times211\to322\times\mathrm{BH}$ で $\alpha=0.1$ のとき約 2.5 倍、$0.2$ のとき約 5 倍(Witte & Mummery arXiv:2412.03655)で、まだ入れていない。入れると、GW241011 の主星からの $f$ の上限は約 1.6 倍になる。(322, 544) の固定点の率($322\times322\to544\times\mathrm{BH}$、$544\times544\to322\times\infty$)も主要項で、降下の時間は前者の率に比例し、後者の率の平方根に反比例する。こちらの補正は見積もっていない。
5. **表の分解能**: スピンの進み具合は段の幅の 1% 刻みで持ち、最初の刻みを越えるまでは初期のスピンを返す。そのため表の節の上でも、スピンで 0.01 以下のずれがある(節の上での確かめで最大 0.006)。約束の 0.03 の中に入っている。
6. **入力は呼ぶ側が決める**: 生まれたときのスピン、質量(「入力の質量」)、年齢の分布(世代ごと)は、集団解析の側で決める。固定点の領域では $f$ と年齢は $f^2T$ でしか入らないので、$f$ の制限は年齢の仮定にそのまま比例して動く($f\propto T^{-1/2}$)。
7. **約束は基準の運動論への忠実さである**。基準の運動論そのものの精度は別で、超放射の率について次のことがわかっている(E19)。
   - 連分数法の表のない範囲(322 の $\alpha<0.1$、211 の $\alpha<0.03$)は解析式を使う。多倍長の連分数法と比べると、322 の解析式は 322 と 211 の臨界のあいだのスピンで 3–13% 小さく($\alpha=0.05$–0.10)、高いスピン($\chi\gtrsim0.7$)では 5–23% 大きい。臨界のあいだでは、322 から育つ BH の降下を 5–20% 遅く見積もることになる。切り替えの $\alpha$ での率の飛びは、322 で $-31\%$ から $+14\%$、211 で $-12\%$ から $+2\%$(スピンによる)。
   - 322 の表(倍精度)は、$\alpha=0.10$–0.125 の低いスピンで、節ごとに最大 9% ずれている($\mathrm{Im}\,\omega/\mathrm{Re}\,\omega\sim10^{-17}$ で倍精度の限界)。$\alpha\ge0.146$ では 0.05% 以内。
   - どちらも率の表を多倍長で作り直し、値の表を作り直せばなくなる(未着手)。それまでは、これらが作る段差の時刻の折れに印 5 をつけている。窓の数値には効かない。
