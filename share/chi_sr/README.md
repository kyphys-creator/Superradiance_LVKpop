# chi_SR: 自己相互作用のある ALP の超放射で、年齢 T のあとの BH のスピン

集団解析(モンテカルロの標本ごとに呼ぶ)のための速い関数。numpy と scipy だけで動く。未発表の研究の一部なので、共有は共同研究者のあいだに限る。

**2026-11-10 の更新(研究ノート E12)**: 準平衡の側で 322 の超放射を落としていたため、スピンが 211 の臨界より下に行けなかった。これを直し、322 の臨界まで下がるようにした($f\gtrsim10^{14}$–$10^{15}$ GeV で効く。窓の $f\sim10^{12}$ GeV の値は変わらない)。印 4 を加え、印 3 の判定を変えた。

## 使い方

```python
from chi_sr import ChiSR
model = ChiSR("chi_sr_tables.npz")
chi_T, regime = model(M_msun, chi0, T_yr, mu_eV, f_GeV)   # どれも配列でよい(ブロードキャスト)
```

| 入力 | 単位 | 意味 |
|---|---|---|
| `M_msun` | $M_\odot$ | BH の質量 |
| `chi0` | — | 生まれたときのスピン($0\le\chi_0<1$) |
| `T_yr` | 年 | 年齢(生まれてから合体まで) |
| `mu_eV` | eV | ALP の質量 $\mu$ |
| `f_GeV` | GeV | ALP の崩壊定数 $f$(自己相互作用 $\lambda=\mu^2/f^2$、引力) |

範囲の外の入力(有限でない値、$\chi_0\notin[0,1)$、$M,\mu,f\le0$、$T<0$)は `ValueError` で止まる。

出力の `chi_T` は年齢 $T$ のあとのスピン、`regime` はどの領域で計算したかの印である。

| `regime` | 意味 |
|---|---|
| 0 | 超放射しない($\chi_0$ が 211 と 322 の臨界以下。$m\ge3$ は入れていない)。$\chi_T=\chi_0$ |
| 1 | 自己相互作用の準平衡(211・322 の二準位の固定点、$\alpha\le0.15$)。322 の臨界まで下がりうる |
| 2 | 自由場(211 が飽和して臨界へ、そのあと 322 の段階)。または 322 から先に育つ BH で、自己相互作用が飽和までに効かない場合 |
| 3 | この模型の外。$\chi_T=\chi_0$ を返す(下の「限界」1) |
| 4 | 準平衡だが $0.15<\alpha\le0.30$。二準位の近似が粗い(限界 2)。値は計算して返す |

速さ: $10^6$ 個の標本で約 0.6 秒(Mac Studio、numpy)。

## 模型

- **重力の微細構造定数**: $\alpha=GM\mu/\hbar c=0.0748\,(M/10M_\odot)(\mu/10^{-12}\,\mathrm{eV})$。
- **超放射の率**: Kerr 時空の Klein–Gordon 方程式を連分数法(Dolan, arXiv:0705.2880)で解いた表を使う。範囲は 211 で $\alpha\ge0.03$、322 で $0.1\le\alpha\le0.52$。範囲の外は解析式(Baumann+ arXiv:1908.10370 の式 2.32–2.34)。占有数の率で、振幅の率の 2 倍。
- **自己相互作用の過程**: $211\times211\to322\times\mathrm{BH}$ と $322\times322\to211\times\infty$(Baryakhtar+ arXiv:2011.11646、以下 BGLS)。占有数を $\varepsilon=N/(GM^2/\hbar c)$ で数えると、率は次のとおり($M_\mathrm{Pl}=1.22\times10^{19}$ GeV)。
  - $\gamma_\mathrm{BH}=4.3\times10^{-7}\alpha^{11}(M_\mathrm{Pl}/f)^4\tilde r_+\mu$
  - $\gamma_\infty=1.1\times10^{-8}\alpha^8(M_\mathrm{Pl}/f)^4\mu$
- **準平衡**(BGLS の式 34–36 の右辺を 0 とおいた固定点): $u=\gamma_\mathrm{BH}\varepsilon_{211}^2$ は $3u^2+(2\gamma_{322}-4\gamma_\infty\gamma_{211}/\gamma_\mathrm{BH})u-\gamma_{322}^2=0$ の正の根で、$\varepsilon_{322}=(u+\gamma_{322})/(2\gamma_\infty\varepsilon_{211})$、$\dot\chi=-3\gamma_\infty\varepsilon_{211}\varepsilon_{322}^2$。
  - $\gamma_{322}\to0$ で BGLS の式 55 に戻る。211 の臨界より下では、211 は吸収されるが $322\times322\to211\times\infty$ で補充され、$\dot\chi\simeq-\tfrac32\gamma_{322}\sqrt{|\gamma_{211}|/\gamma_\infty}$ で 322 の臨界まで下がる。
  - どちらの側でも $\dot\chi=\mu(f/M_\mathrm{Pl})^2H(\alpha,\chi)$ で、$f$ と $\mu$ は前の因子にしか入らない。そこで $I(\alpha,\chi)=\int_\chi^{0.995}d\chi'/|H|$ を表にし、$I(\alpha,\chi_T)=I(\alpha,\chi_0)+\tau$($\tau=\mu(f/M_\mathrm{Pl})^2T$)を解く。
  - スピンは $(\alpha,\chi_0,\tau)$ の 3 つの量だけで決まる。したがって $f$ と年齢 $T$ は $f^2T$ の形でしか入らない。
- **領域の判定**(BGLS の式 53・56): 次の二つが、どちらも自由場で飽和する量 $\chi_0-\chi_c^{(211)}$ より小さければ準平衡、そうでなければ自由場とする。
  - 準平衡の占有数 $\varepsilon_\mathrm{eq}$
  - 行き過ぎの占有数 $\varepsilon_\mathrm{th}=\sqrt{2\gamma_\mathrm{SR}\ln(GM^2)/\gamma_\mathrm{BH}}$
- **準平衡の側**: 1 個の量子から $\varepsilon_\mathrm{eq}$ まで育つ時間を年齢から引き、行き過ぎで失う $\varepsilon_\mathrm{th}$ を初期スピンから引く。
- **自由場の側**: 211 は 1 個の量子から $\ln N_\mathrm{sat}\approx180$ 回の $e$-fold で飽和し、臨界スピン($m\Omega_H=E_n$)まで落ちる。BH の質量の減少を入れる。そのあと:
  - $f\le10^{17}$ GeV: $211\times211\to322\times\mathrm{BH}$ が 322 をすぐに育てるので、準平衡と同じ固定点で 322 の臨界へ下がる。
  - $f>10^{17}$ GeV: 322 を $t=0$ から 1 個の量子として $e$-fold を積む($f\to\infty$ で自由場の文献と同じ数え方)。
- **322 から先に育つ BH**($\chi_c^{(322)}<\chi_0\le\chi_c^{(211)}$): 322 が 1 個の量子から自由に飽和するのは、次の二つが、どちらも飽和の量 $(\chi_0-\chi_c^{(322)})/2$ より大きいときだけとし、そのときは自由場(印 2)、そうでなければ印 3 とする。
  - $322\times322\to544\times\mathrm{BH}$ の行き過ぎ $\sqrt{2\gamma_{322}\ln(GM^2)/\gamma'_\mathrm{BH}}$、$\gamma'_\mathrm{BH}=1.9\times10^{-9}\alpha^{11}(M_\mathrm{Pl}/f)^4\tilde r_+\mu$(BGLS Table V)
  - 吸収される 211 が補充され始める占有数 $\sqrt{|\gamma_{211}|/\gamma_\infty}$
  - $\mu=0.71\times10^{-12}$ eV の例では、自由場になるのは $f\approx(1$–$3)\times10^{17}$ GeV から。

## 照合

研究ノート E11・E12 にまとめたもの。
- **運動論の ODE**(BGLS の式 34–36 を 1 個の量子から解いたもの、BH の質量は固定)との比較:
  - 準平衡の側(印 1・4): GW241011 の主星($19.6M_\odot$、$\chi_0=0.78$、$\mu=0.71\times10^{-12}$ eV)の $f=10^{11}$–$10^{16}$ GeV、$T\le10^{10}$ 年、$15$–$30M_\odot$ の $f=10^{13}$–$10^{15}$ GeV で、差は最大 0.0033。211 の臨界より下への降下も合う(例: $25M_\odot$、$f=10^{15}$ GeV、$3\times10^9$ 年で ODE 0.3275、この関数 0.3282)。
  - 自由場の側($f=3\times10^{16}$ GeV): 差は最大 0.053。
  - $f>10^{17}$ GeV: ODE の解法が止まるので確かめていない。
- **自由場の半解析**との比較($f=10^{19}$ GeV、無作為な 400 点、E11): 差の中央値は $3\times10^{-7}$、93.5% が 0.01 以内。
- **単体版とプロジェクト版**: 20 万個の標本で完全に一致。

## 限界(使う前に読む)

1. **印 3(322 から先に育つ BH など)**: 211 が超放射せず 322 だけが育つ BH($\chi_c^{(322)}<\chi_0\le\chi_c^{(211)}$)で、自己相互作用が効く場合の扱いがない。
   - この範囲は $\chi_0$ で決まり、質量では決まらない。$\mu=0.71\times10^{-12}$ eV では $\chi_0=0.3$ で約 $15$–$29M_\odot$、$0.5$ で $25$–$51M_\odot$、$0.7$ で $39M_\odot$ 以上。
   - 1 世代目の自然スピンを Beta(0.69, 2.28)(arXiv:2607.01317 の事後分布の中央値)とすると、$8$–$50M_\odot$ のどの質量でも 1–2 割が印 3 になる。
   - $\chi_0$ を返すのは、窓の $f\sim10^{12}$ GeV ではおそらく良い近似だが、$f\gtrsim10^{14}$ GeV では回転を失いうるので悪い近似である。
   - ほかに、準平衡で $\alpha<0.01$ または $>0.30$ の点、$\alpha>0.5$ の点も印 3。
   - 集団解析では、印 3 の標本を $\chi_T\in[\chi_c^{(322)},\chi_0]$ のどちらの端に置くかで結果がどれだけ動くかを見てほしい。
2. **$\alpha>0.15$(印 4)**: 433($\alpha\gtrsim0.15$)や 411($\alpha\gtrsim0.2$)が育つので、二準位の近似は粗い。$\mu=0.71\times10^{-12}$ eV では $28$–$56M_\odot$。
3. **$f>10^{17}$ GeV の 322 の段階**: 確かめていない。$f=10^{17}$ GeV の切り替えでスピンが最大 0.15 ほど飛ぶ。
4. **自己相互作用の率は主要項**: Kerr 時空での補正は、$211\times211\to322\times\mathrm{BH}$ で $\alpha=0.1$ のとき約 2.5 倍、$0.2$ のとき約 5 倍(Witte & Mummery arXiv:2412.03655)で、まだ入れていない。入れると、GW241011 の主星からの $f$ の上限は約 1.6 倍になる。
5. **質量の減少**: 準平衡の側では BH の質量を固定した(補正は回転を失う時間で 2–5%)。自由場の側では雲のエネルギーをすべて引いている。この違いで、領域の境目でスピンが 0.015 ほど飛ぶ。
6. **入力は呼ぶ側が決める**: 生まれたときのスピンと年齢の分布(世代ごと)は、集団解析の側で決める。$f$ と年齢は $f^2T$ でしか入らないので、$f$ の制限は年齢の仮定にそのまま比例して動く($f\propto T^{-1/2}$)。
