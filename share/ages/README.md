# ages: BH の年齢(生まれてから合体まで)の分布の模型

集団解析で、BH の年齢を分布として周辺化するための部品。numpy だけで動く。`share/chi_sr/` の $\chi_\mathrm{SR}$ と組で使う(2 世代目の生まれたときのスピンは `share/remnant/`)。未発表の研究の一部。

$\chi_\mathrm{SR}$ は年齢 $T$ を入力にとるが、年齢は観測されない。しかも固定点の領域では、スピンは $\tau=\mu(f/M_\mathrm{Pl})^2T$ だけで決まるので、$f$ の制限は年齢の仮定にそのまま比例して動く($f\propto T^{-1/2}$)。年齢の分布をどう置いたかを明示し、そのパラメータを動かせるようにするのが、この部品の役目である。根拠と数値は研究ノート E22。

## 使い方

```python
from ages import AgeModel
from chi_sr import ChiSR

am = AgeModel()                                  # 既定の模型
model = ChiSR("chi_sr_tables.npz")
T = am.nodes(2, z_merge, K=32)                   # 2 世代目の年齢 [yr]。形は z_merge の形 + (K,)
chi, regime = model(M[:, None], chi0[:, None], T, mu, f)
# chi の K についての平均(や分布)が、年齢について周辺化した量になる。節の重みはどれも 1/K
```

| 関数 | 中身 |
|---|---|
| `nodes(gen, z, K)` | 年齢の求積の節 [yr]。確率 $(k+1/2)/K$ の分位点($k=0,\dots,K-1$) |
| `quantile(gen, z, p)` | 確率 $p$ の分位点の年齢 [yr] |
| `cdf(gen, z, T)` | 年齢が $T$ 以下である確率 |
| `pdf_lnT(gen, z, T)` | 確率密度 $dP/d\ln T$ |
| `sample(gen, z, rng)` | 年齢の標本 [yr] |
| `tmax(gen, z)` | 年齢の上限 [yr] |
| `cosmic_time(z)`、`z_at(t)` | 宇宙の年齢 [yr] と赤方偏移 |

`gen` は世代(1 か 2)、`z` は合体の赤方偏移(配列でよい)。時間と年齢の単位はすべて年。模型を作る時間は 0.04 秒なので、パラメータを変えるたびに作り直してよい。`nodes` は $2\times10^5$ 個の $z$ で $K=32$ のとき 0.4 秒。

## 模型

年齢 $T$ は、BH が生まれてから、その BH を含む連星が合体するまでの時間である。合体の赤方偏移 $z_m$ での宇宙の年齢を $t_m$ とする。

**1 世代目**(`gen = 1`): $T$ は星形成から合体までの遅れ。
$$p_1(T\,|\,z_m)\propto T^{-\kappa_1}\,\psi(t_m-T),\qquad T_\mathrm{min,1}\le T\le t_m-t_\mathrm{start}$$
$T^{-\kappa_1}$ は遅れの分布、$\psi$ は宇宙の星形成率(Madau & Dickinson 2014 の式 15)、$t_\mathrm{start}$ は星形成の始まり($z=20$)。

**2 世代目**(`gen = 2`): $T$ は、親の合体(この BH ができた時刻)から次の合体までの時間。
$$p_2(T\,|\,z_m)\propto p_D(T)\,R_1(t_m-T),\qquad T_\mathrm{lo}\le T\le\min(T_\mathrm{hi},\,t_m-t_\mathrm{start}-T_\mathrm{min,1})$$
$p_D$ は時間の分布の形(対数一様か対数正規)、$R_1(t)=\int T'^{-\kappa_1}\psi(t-T')\,dT'$ は同じ 1 世代目の模型の合体率(親の合体が起きた時刻の重み)。

| 引数 | 既定 | 意味 |
|---|---|---|
| `kappa1` | 1 | 1 世代目の遅れの分布のべき。1 は孤立連星の標準の形、0 は古い星団のように長い年齢に寄る |
| `tmin1` | $10^7$ yr | 1 世代目の遅れの下限 |
| `family2` | `"loguniform"` | 2 世代目の時間の分布の形。`"lognormal"` も選べる |
| `t2lo`、`t2hi` | $10^6$、$10^{10}$ yr | 2 世代目の年齢の下限と上限(上限は宇宙の年齢でも切れる) |
| `t2med`、`s2` | $10^8$ yr、1 dex | 対数正規のときの中央値と幅 |
| `sfr_weight` | `True` | 星形成率の重み $\psi$ を入れる(`False` で $\psi=1$) |
| `parent_weight` | `True` | 親の合体率の重み $R_1$ を入れる(`False` で $R_1=1$) |
| `z_start` | 20 | 星形成の始まり(結果にはほとんど効かない) |
| `H0`、`Om` | 67.4、0.315 | 平坦な $\Lambda$CDM(Planck 2018 の要旨の値) |

## 年齢の分布の例

5%、16%、50%、84%、95% の分位点(年)。1 世代目は $z_m=0.2$、2 世代目は $z_m=0.05$(GW241011 の赤方偏移)。

| 世代 | 組 | 引数 | 5% | 16% | 50% | 84% | 95% |
|---|---|---|---|---|---|---|---|
| 1 | 既定 | — | $1.7\times10^7$ | $5.5\times10^7$ | $1.5\times10^9$ | $6.9\times10^9$ | $8.6\times10^9$ |
| 1 | 古い | `kappa1=0` | $1.4\times10^9$ | $3.4\times10^9$ | $6.6\times10^9$ | $8.6\times10^9$ | $9.6\times10^9$ |
| 1 | 重みなし | `sfr_weight=False` | $1.4\times10^7$ | $3.1\times10^7$ | $3.3\times10^8$ | $3.6\times10^9$ | $7.8\times10^9$ |
| 2 | 既定(広い) | — | $1.8\times10^6$ | $6.0\times10^6$ | $2.7\times10^8$ | $5.3\times10^9$ | $8.4\times10^9$ |
| 2 | 星団の目安 | `family2="lognormal", t2med=5e7, s2=0.7, t2lo=1e5` | $3.6\times10^6$ | $1.0\times10^7$ | $5.2\times10^7$ | $2.7\times10^8$ | $8.5\times10^8$ |
| 2 | 遅い | `t2lo=3e8` | $3.9\times10^8$ | $6.9\times10^8$ | $3.1\times10^9$ | $7.6\times10^9$ | $9.2\times10^9$ |
| 2 | AGN 円盤 | `t2lo=1e4, t2hi=1e7` | $1.4\times10^4$ | $3.0\times10^4$ | $3.2\times10^5$ | $3.3\times10^6$ | $7.1\times10^6$ |

2 世代目の組は目安で、文献にある分布そのものではない。2 世代目の年齢の分布を直接示した論文は見つかっていない(プロジェクトの `Refs/notes/astro_inputs.md` §3)。先行研究の「どの BH も年齢は 1 Myr–2.2 Gyr の対数一様」(arXiv:2609.02678)は、`AgeModel(t2lo=1e6, t2hi=2.2e9, parent_weight=False)` の `gen = 2` で再現できる。

## 使うときの注意

1. **年齢の模型は仮定である**。$\chi_\mathrm{SR}$ のような精度の約束はない。結果は、年齢の模型のパラメータと組にして示す。
2. **$f$ と年齢は縮退する**。年齢をすべて $k$ 倍にして $f$ を $k^{-1/2}$ 倍にしても、固定点の領域のスピンは変わらない(確率の差は 0.003 以下。研究ノート E22)。1 世代目の年齢は宇宙の年齢と星形成史で桁が決まるので、$f$ を測る物差しになる。2 世代目の年齢の尺度は、$f$ と一緒にデータから制限される量である。
3. **節の数**: 確率を節の平均で出すと、$1/K$ 刻みになる。$K=32$ で 0.016、$K=100$ で 0.005 の誤差(E22)。
4. **年齢の範囲**: $\chi_\mathrm{SR}$ の照合の範囲は年齢 $10^5$–$1.4\times10^{10}$ 年。AGN 円盤の組のように $10^5$ 年より短い年齢を含むときは、その範囲の外になる。
5. **入れていないもの**: BH ができるまでの時間(星形成の 3–20 Myr あと)、金属量による形成効率の違い(入れると 1 世代目は古い側に寄る)、星団ごとの違い、AGN 円盤での降着(スピンを戻しうる)。
6. **精度**: 分位点と累積分布は表から補間する。直接の数値積分との差は、累積分布で $3\times10^{-4}$ 以下、分位点の年齢で 0.5% 以下。

確かめと数値は、プロジェクトの `research/calc/e22_ages.py`(出力 `research/calc/out/e22.json`)。
