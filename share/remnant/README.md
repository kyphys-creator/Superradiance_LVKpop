# remnant: 合体の残骸の質量・スピン・キック(2 世代目の BH が生まれたときの質量とスピン)

集団解析で、2 世代目の BH の生まれたときのスピンと質量を、親(1 世代目)の集団から作るための部品。numpy だけで動く。`share/chi_sr/` の $\chi_\mathrm{SR}$、`share/ages/` の年齢の模型と組で使う。未発表の研究の一部。

2 世代目の BH は合体の残骸で、スピン 0.69 のまわりで生まれる。ただし一つの値ではない。幅と裾は親の質量比とスピンで決まり、ボソンがあれば、親が合体までに回転を失うので $f$ にもよる。生まれたときのスピンを一つの値(0.72 や 0.78)に固定せず、親の集団から分布として作るのが、この部品の役目である。根拠と数値は研究ノート E23。

## 使い方

```python
import numpy as np
import remnant

rng = np.random.default_rng(0)
out = remnant.merge(m_a, m_b, chi_a, chi_b, rng)   # 親の質量と、合体のときのスピンの大きさ(配列)
out["M"]        # 残骸の質量(親の質量と同じ単位) = 2 世代目の生まれたときの質量
out["chi"]      # 残骸のスピン = 2 世代目の生まれたときのスピン
out["vkick"]    # 反跳(キック)の速さ [km/s]
```

渡した先では、まず `python remnant.py` を走らせる(決まった入力での値を照らす。合えば `ok` と出る)。

| 関数 | 中身 |
|---|---|
| `merge(m_a, m_b, chi_a, chi_b, rng, correct=False)` | 親の対から残骸を一つずつ作る。スピンの向きは等方に引く。返り値は `M`、`chi`、`vkick`、`q`、`cosb`、`cosg` の dict |
| `final_spin(q, a1, a2, cosb, cosg, cosal, correct=False)` | 残骸のスピンの大きさ |
| `final_mass_fraction(q, a1, a2, cosb, cosg)` | 残骸の質量 / 親の質量の和 |
| `kick(q, a1, a2, cosb, cosg, dphi, cos_theta)` | キックの速さ [km/s] |
| `selfcheck()` | 決まった入力での値の照合(合わない項目のリストを返す) |

添え字 1 は重いほう、$q=m_2/m_1\le1$。`cosb`、`cosg` はスピン 1、2 と軌道角運動量のなす角の余弦、`cosal` はスピンどうしのなす角の余弦、`dphi` は二つのスピンの方位角の差。`merge` は質量の順をそろえるので、親をどちらの順で渡してもよい。$10^6$ 対で 0.2–0.3 秒。

## 式と出どころ

どれも数値相対論の当てはめで、式番号は arXiv の本文で照合した。式そのものは `remnant.py` の冒頭に書いてある。

| 量 | 出どころ | 精度の目安 |
|---|---|---|
| スピン | Hofmann, Barausse & Rezzolla 2016(arXiv:1605.01938)の式 13–16、Table 1 の上段 | 残差は揃ったスピンで 0.002、一般の向きで 0.006。一般の向きでは 0.005 だけ大きめに出る(`correct=True` で式 18 の補正を入れると 0.001) |
| 質量 | Barausse, Morozova & Rezzolla 2012(arXiv:1206.3803)の式 18 | 放出エネルギーの 1 割以内 |
| キック | Gerosa & Kesden 2016(arXiv:1605.01067)の式 44–47、スピンの組み合わせは式 36 | 粗い(下の注意 3) |

決まった入力での値: 等質量・無スピンでスピン 0.68646・質量 0.95173 倍、$q=1/3$・無スピンで 0.540、等質量で 0.5 ずつ揃ったスピンで 0.832、無スピンのキックの最大は $q=0.362$ で 175.2 km/s。

Beta(0.69, 2.28) は、1 世代目の生まれたときのスピンの推定(arXiv:2607.01317 の事後分布の中央値)。下の 2 行は $\mu=0.71\times10^{-12}$ eV で、親の年齢は `share/ages/` の既定の 1 世代目。残骸の質量は、基準の組で親の質量の和の 0.954 倍(5–95% は 0.945–0.962 倍)。

## 親の集団とつなぐ

親のスピンは**合体のときの値**を渡す。ボソンがあると、親は生まれてから合体するまでに超放射で回転を失うので、生まれたときのスピンに $\chi_\mathrm{SR}$ を通した値である。2 世代目は、生まれてから次の合体まで、もう一度 $\chi_\mathrm{SR}$ を通す。

```python
from ages import AgeModel
from chi_sr import ChiSR
import remnant

am, model = AgeModel(), ChiSR("chi_sr_tables.npz")
rng = np.random.default_rng(seed)                  # mu, f を変えても同じ seed にする(注意 5)

# 親(1 世代目)の対: 質量と、生まれたときのスピン。分布は 1 世代目の集団の模型と同じものを使う
q = rng.uniform(0.5, 1.0, n)
m_a = (M_2g / 0.952) / (1 + q); m_b = q * m_a      # 残骸が M_2g になる親の質量(注意 4)
chi_a0, chi_b0 = rng.beta(0.69, 2.28, n), rng.beta(0.69, 2.28, n)

# 親が合体するまでの超放射(親の年齢は 1 世代目の年齢)
chi_a, reg_a = model(m_a, chi_a0, am.sample(1, np.full(n, z_parent), rng), mu, f)
chi_b, reg_b = model(m_b, chi_b0, am.sample(1, np.full(n, z_parent), rng), mu, f)

# 合体: 2 世代目の生まれたときの質量とスピン
out = remnant.merge(m_a, m_b, chi_a, chi_b, rng)

# 2 世代目が次に合体するまでの超放射(年齢は 2 世代目の年齢)
chi_2g, reg_2g = model(out["M"], np.minimum(out["chi"], 0.9989), am.sample(2, np.full(n, z_merge), rng), mu, f)
# chi_2g の分布が、この事象の主星のスピンの(2 世代目だとしたときの)予言になる
```

`np.minimum(…, 0.9989)` は $\chi_\mathrm{SR}$ の入力の上限に合わせるためのもの(基準の組では、切られる残骸はない)。

## 使うときの注意

1. **親の集団は仮定である**。上の表のとおり、0.69 以上で生まれる割合は、親が回らなければ 0、ほかの組では親の質量比とスピンの分布で 0.25–0.52 に動く。親のスピンと質量比の分布は、1 世代目の集団の模型のパラメータと共通にして、データから同時に決める。
2. **向きは等方に引く**(星団の中で対になった BH)。孤立連星のように向きが揃う親や、AGN 円盤のように降着のある親には使えない。
3. **キックの式は粗い**。同じ親のスピンで、数値相対論の代理模型より平均で 10 倍大きいという比較がある(arXiv:2503.21278)。親のスピンが大きいとき(0.5)、残るのは 0.6–3% だけ($v_\mathrm{esc}=50$–100 km/s)で、その分布は式の細部(位相を一つにまとめた近似、$\boldsymbol\Delta$ の符号)で動く。球状星団の模擬計算の値(arXiv:1906.10260。親のスピン 0.5 で中央値 0.62)は再現できなかった(この式では 0.71–0.72。研究ノート E23)。**既定ではキックで選ばない**。選ぶ場合は、`out["vkick"] < v_esc` を、脱出速度を 50–300 km/s で動かして不定性ごと使う。
4. **質量**: 残骸の質量は親の質量の和の 0.945–0.962 倍(5–95%)なので、和を $M_\mathrm{2G}/0.952$ にとれば、残骸は $M_\mathrm{2G}$ の $\pm1\%$ に入る。親の質量は、超放射で雲に移る分だけ減る(平均 0.5%、99 パーセンタイルでも 3.5%)が、入れていない。
5. **乱数**: 確率を標本の平均で出すので、$\mu$ や $f$ を変えるたびに乱数を変えると、尤度がざらつく。同じ seed を使う。
6. **$\chi_\mathrm{SR}$ の印**: 親にも 2 世代目にも、`share/chi_sr/README.md` の印 3・4・5 の扱い(落とさず両端で挟む)がそのまま要る。$\mu=0.71\times10^{-12}$ eV、$19.6\,M_\odot$ の 2 世代目では、印 3–5 は 6% 以下で、確率を最大 0.03 動かす。
7. **スピンの式の範囲**: 重いほうのスピンが 0.99 を越えて軌道角運動量にほぼ揃い、質量比が小さい(0.03 付近)とき、当てはめは 1 をわずかに越える(最大 0.0014)。`merge` は 1 で切る。

確かめと数値は、プロジェクトの `research/calc/e23_natal2g.py`(出力 `research/calc/out/e23.json`)。
