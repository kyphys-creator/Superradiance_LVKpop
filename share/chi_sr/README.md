## 使い方

```python
from chi_sr import ChiSR
model = ChiSR("chi_sr_tables.npz")
chi_T, regime = model(M_msun, chi0, T_yr, mu_eV, f_GeV)   # どれも配列でよい(ブロードキャスト)
```

| 入力 | 単位 | 意味 |
|---|---|---|
| `M_msun` | $M_\odot$ | BH の質量 |
| `chi0` | — | 生まれたときのスピン($0\le\chi_0<1$) |
| `T_yr` | 年 | 年齢(生まれてから合体まで) |
| `mu_eV` | eV | ALP の質量 $\mu$ |
| `f_GeV` | GeV | ALP の崩壊定数 $f$(自己相互作用 $\lambda=\mu^2/f^2$、引力) |

範囲の外の入力(有限でない値、$\chi_0\notin[0,1)$、$M,\mu,f\le0$、$T<0$)は `ValueError` で止まる。

出力の `chi_T` は年齢 $T$ のあとのスピン、`regime` はどの領域で計算したかの印である。

| `regime` | 意味 |
|---|---|
| 0 | 超放射しない($\chi_0$ が 211 と 322 の臨界以下で、433 も年齢のうちに飽和しない)。$\chi_T=\chi_0$ |
| 1 | 自己相互作用の固定点(三準位)。211 から育つ BH も 322 から育つ BH も、322 の臨界まで下がりうる。三準位の外の準位は年齢のうちに育たない |
| 2 | 自由場(211 が飽和して臨界へ、そのあと 322 の段階)。または 322 から育つ BH で、自己相互作用が飽和までに効かず 322 が飽和する場合(どちらも BH の質量の減少を入れる) |
| 3 | この模型の外。$\chi_T=\chi_0$ を返す: 固定点で $\alpha<0.01$ または $>0.30$、$\alpha>0.5$、211・322 は超放射しないが 433($m=3$)が年齢のうちに飽和しうる点 |
| 4 | 値は計算して返すが、模型の外の準位が年齢のうちに育ちうる: 固定点で 411、433、211 の臨界より上の 544(限界 2)、または自由場で止まったスピンから 433 が飽和しうる。値は $m\le2$ で計算したまま |

速さ: $10^6$ 個の標本で約 0.8 秒(Mac Studio、numpy)。

## 模型

- **重力の微細構造定数**: $\alpha=GM\mu/\hbar c=0.0748\,(M/10M_\odot)(\mu/10^{-12}\,\mathrm{eV})$。
- **超放射の率**: 211・322 は Kerr 時空の Klein–Gordon 方程式を連分数法(Dolan, arXiv:0705.2880)で解いた表(211 で $\alpha\ge0.03$、322 で $0.1\le\alpha\le0.52$)。範囲の外と 433・544 は解析式(Baumann+ arXiv:1908.10370 の式 2.32–2.34)。占有数の率で、振幅の率の 2 倍。
- **自己相互作用の過程**(Baryakhtar+ arXiv:2011.11646、以下 BGLS、Table V・VI。占有数を $\varepsilon=N/(GM^2/\hbar c)$ で数え、率は $\mu(M_\mathrm{Pl}/f)^4$ を掛ける。BH が吸収する過程には $\tilde r_+$ も掛ける。$M_\mathrm{Pl}=1.22\times10^{19}$ GeV):

  | 過程 | 率 |
  |---|---|
  | $211\times211\to322\times\mathrm{BH}$ | $4.3\times10^{-7}\alpha^{11}$ |
  | $322\times322\to211\times\infty$ | $1.1\times10^{-8}\alpha^{8}$ |
  | $322\times322\to544\times\mathrm{BH}$ | $1.9\times10^{-9}\alpha^{11}$ |
  | $544\times544\to322\times\infty$ | $4.4\times10^{-11}\alpha^{8}$ |
  | $322\times544\to211\times\infty$ | $6.1\times10^{-11}\alpha^{8}$ |
  | $544\times544\to211\times\infty$ | $4.2\times10^{-13}\alpha^{8}$ |

- **固定点**: 三準位の式の安定な固定点で回転を失う。
  - 211 の臨界より上: (211, 322)。$\varepsilon_{211}=(2/\sqrt3)\sqrt{\gamma_{211}\gamma_\infty}/\gamma_\mathrm{BH}$(BGLS の式 55 に $\gamma_{322}$ の補正)。
  - 211 の臨界より下: 211 が空の (322, 544)。$\varepsilon_{322}=(2/\sqrt3)\sqrt{\gamma_{322}\gamma_d}/\gamma_c$、$\dot\chi=-2\gamma_{322}\varepsilon_{322}$。211–322 の組と同じ形。
  - 自己相互作用の率はどれも $(M_\mathrm{Pl}/f)^4$ に比例するので、どちらでも $\dot\chi=\mu(f/M_\mathrm{Pl})^2H(\alpha,\chi)$。そこで $I(\alpha,\chi)=\int_\chi^{0.995}d\chi'/|H|$ を表にし、$I(\alpha,\chi_T)=I(\alpha,\chi_0)+\tau$($\tau=\mu(f/M_\mathrm{Pl})^2T$)を解く。
  - スピンは $(\alpha,\chi_0,\tau)$ の 3 つの量だけで決まる。したがって $f$ と年齢 $T$ は $f^2T$ の形でしか入らない。
- **211 から育つ BH の判定**(BGLS の式 53・56): 固定点の占有数 $\varepsilon_\mathrm{eq}$ と行き過ぎ $\varepsilon_\mathrm{th}=\sqrt{2\gamma_{211}\ln(GM^2)/\gamma_\mathrm{BH}}$ が、どちらも飽和の量 $\chi_0-\chi_c^{(211)}$ より小さければ固定点、そうでなければ自由場。固定点では、1 個の量子から育つ時間を年齢から引き、行き過ぎで失う $\varepsilon_\mathrm{th}$ を初期スピンから引く。
- **322 から育つ BH**($\chi_c^{(322)}<\chi_0\le\chi_c^{(211)}$)の判定: 同じ形で、$\varepsilon'_\mathrm{eq}=(2/\sqrt3)\sqrt{\gamma_{322}\gamma_d}/\gamma_c$ と $\varepsilon'_\mathrm{th}=\sqrt{2\gamma_{322}\ln(GM^2)/\gamma_c}$ を $(\chi_0-\chi_c^{(322)})/2$ と比べる。固定点では、322 が育つ時間を年齢から引き、$2\varepsilon'_\mathrm{th}$ を初期スピンから引く。そうでなければ 322 が飽和して、BH の質量の減少を入れた 322 の臨界へ。$\mu=0.71\times10^{-12}$ eV の例では、自由場になるのは $f\approx1.7\times10^{17}$ GeV から。
- **臨界スピン**: 相対論的な率(211・322 の表、外は解析式)が 0 になるスピンを $\alpha=0.003$–0.6 で表にし、固定点の表、領域の判定、自由場の飽和のすべてで使う。率の表の端($\chi=0.995$)より上に臨界がある点($\alpha\approx0.45$ 以上)で、率を引けない BH は印 3。
- **表の引き方**: 両隣の $\alpha$ の節で $I$ に $\tau$ を足してそれぞれ厳密に逆に引き、$\alpha$ について線形に混ぜる($\tau\to0$ で $\chi_T=\chi_0$)。
- **自由場の側**: 211 は 1 個の量子から $\ln N_\mathrm{sat}\approx180$ 回の $e$-fold で飽和し、臨界スピン($m\Omega_H=E_n$)まで落ちる。BH の質量の減少を入れる。そのあと:
  - $f\le10^{17}$ GeV: 固定点の表で 322 の臨界へ下がる。
  - $f>10^{17}$ GeV: 322 を $t=0$ から 1 個の量子として $e$-fold を積む(限界 3)。

## 照合

研究ノート E11・E14 にまとめたもの。
- **三準位の運動論の ODE**(1 個の量子から、各過程に自発的な放出を入れたもの、BH の質量は固定)との比較:
  - 固定点の領域(印 1・4)の 41 点で、差は最大 0.0008。211 から育つ BH(GW241011 の主星 $19.6M_\odot$・$\chi_0=0.78$、$25$、$30M_\odot$)と 322 から育つ BH($45M_\odot$・$\chi_0=0.7$、$20M_\odot$・0.3、$30M_\odot$・0.5、$15M_\odot$・0.25)、$\mu=0.71\times10^{-12}$ eV、$f=10^{13}$–$10^{16}$ GeV、$T\le10^{10}$ 年。
  - 例: GW241011 の主星、$f=10^{16}$ GeV、$10^9$ 年で ODE 0.3413、この関数 0.3407。$45M_\odot$($\chi_0=0.7$)、$f=10^{14}$ GeV、$10^{10}$ 年で ODE 0.4694、この関数 0.4698。
  - 自由場の側($3\times10^{16}$–$10^{17}$ GeV): 差は最大 0.048。
- **自由場の半解析**との比較($f=10^{19}$ GeV、無作為な 400 点、E11): 差の中央値は $3\times10^{-7}$、93.5% が 0.01 以内。
- **単体版とプロジェクト版**: 20 万個の標本と、臨界のすぐ上と下の点で、値も印も完全に一致。

## 限界(使う前に読む)

1. **印 3**: 固定点で $\alpha<0.01$ または $>0.30$ の点、$\alpha>0.5$ の点、433($m=3$)が年齢のうちに飽和しうる点(433 の自己相互作用は入れず、自由場の飽和の時間で判定)。433 のために印 3 になるのは、Beta(0.69, 2.28) の 1 世代目・6 Gyr で、$8$–$50M_\odot$・$\mu=0.71\times10^{-12}$ eV なら 0.09%、$8$–$80M_\odot$ なら 4.2%、$\mu=0.89\times10^{-12}$ eV ならそれぞれ 2.6、4.6%。1 世代目の自然スピンを Beta(0.69, 2.28) とし、$8$–$50M_\odot$、$\mu=0.71\times10^{-12}$ eV とすると、$f\le10^{16}$ GeV で印 3 の標本はない。
2. **印 4**: 固定点で、411・433・544 の増加率が BH の降下のあいだに $\ln(GM^2)\approx180$ を超える $e$-fold を稼ぐ点(322 の臨界まで下がった BH は、433 の超放射も見る)。
   - 増加率は、BH が吸収する過程すべてに有限 $\alpha$ の補正(Witte & Mummery の図から読んだ $C_\mathrm{BH}$)を掛けて評価する。このとき 433・544 は $\alpha\gtrsim0.15$、411 は $\alpha\gtrsim0.18$ で、211 の臨界より上で育つ(BGLS の記述と合う)。補正なしでは 433 だけが $\alpha\gtrsim0.27$ で育つ。411 の超放射の率は Leaver の連分数法の表。
   - 211 の臨界より下の (322, 544) の固定点では、$\alpha\le0.30$ で何も育たない。322 から育つ BH と 211 の臨界より下への降下は、ほぼ印 1 になる。
   - 1 世代目の自然スピンを Beta(0.69, 2.28)、$8$–$50M_\odot$、$\mu=0.71\times10^{-12}$ eV、6 Gyr とすると、印 4 は $f=10^{12}$、$10^{14}$、$10^{16}$ GeV で 2.3、2.2、0.4%。
   - 印 4 の値の誤差: 五準位(211・322・411・433・544)の ODE と比べた例($\alpha=0.22$、$\chi_0=0.9$)で最大 0.072。411 のあとに育つ 422 と、433 による $m=3$ の回転の減少は入れていない。
3. **$f>10^{17}$ GeV の 322 の段階**: ODE では、GW241011 の主星の 322 の段階は $f=10^{18}$ GeV で $2.8\times10^7$ 年に終わるが、この関数は 1 個の量子から数えるので数億年かかる。$10^{17}$–$5\times10^{18}$ GeV、$T\approx3\times10^7$–$4\times10^8$ 年で、スピンを最大 0.19 高く返す。$f\gtrsim10^{19}$ GeV では自由場に戻る。
4. **自己相互作用の率は主要項**: Kerr 時空での補正は、$211\times211\to322\times\mathrm{BH}$ で $\alpha=0.1$ のとき約 2.5 倍、$0.2$ のとき約 5 倍(Witte & Mummery arXiv:2412.03655)で、まだ入れていない。入れると、GW241011 の主星からの $f$ の上限は約 1.6 倍になる。
5. **質量の減少と重力波**: 固定点の側では BH の質量を固定した(補正は回転を失う時間で 2–5%)。自由場の側(211 から育つ BH も 322 から育つ BH も)では雲のエネルギーをすべて引いている。この違いで、領域の境目でスピンが 0.016 ほど飛ぶ。雲からの重力波の過程は入れていない。
6. **入力は呼ぶ側が決める**: 生まれたときのスピンと年齢の分布(世代ごと)は、集団解析の側で決める。$f$ と年齢は $f^2T$ でしか入らないので、$f$ の制限は年齢の仮定にそのまま比例して動く($f\propto T^{-1/2}$)。
